# multiscan — the scan engine vendored by this artifact

> This is a component, not an entry point. The **only** guide for evaluating
> this artifact is the [repository README](../README.md); everything here is
> complementary.

`multiscan` is the harness that produced the census: it pulls each target image
once, hands the static scanners the saved tarball and the exported root
filesystem, records per-invocation timing, and normalizes every scanner output
to a single finding schema while keeping each scanner's raw output verbatim.
Every scanner runs as a Docker image, so nothing is installed on the host.

It is driven entirely by a run config; the artifact never asks anyone to edit
source. The two configs it is invoked with are generated at run time:

| Generated by | Config | Used by |
|---|---|---|
| `scripts/render_config.py` | `config/os.yaml` | `./reproduce.sh all` (the full census) |
| `scripts/scan_smoke.sh` | `config/smoke_scan.yaml` | `./reproduce.sh scan-smoke` (Claim #2) |

Both point at the repository-root [`config/scanners.yaml`](../config/scanners.yaml),
which is the authoritative registry of how each scanner is invoked.

## Layout

```
src/scanners/
├── adapters/    one module per scanner: builds its argv, parses its output
├── dockerctl/   Docker lifecycle: pull, run, monitor, export rootfs
├── jobqueue/    restartable work queue (SQLite, or an HTTP coordinator)
├── pipeline/    the worker loop that drives a scan
├── findings/    normalized finding schema, corpus store, aggregation
├── sources/     target-inventory readers (csv / jsonl / txt)
├── report/      HTML rendering of an aggregated run
└── cli.py       the `scanners` command-line entry point
docker/          Dockerfiles for the scanners with no maintained upstream image
scripts/         build-images.sh: builds those images, tagged multiscan/<name>:1
tests/           unit tests for the engine (no network, no containers)
```

The registry covers more scanners than this census uses; the census selects the
14 relevant ones through the `only:` key of its run config.
